# 名刺 大枠

日本の標準サイズ **91 × 55mm**。印刷所へ入稿するなら塗り足し3mmを足して **97 × 61mm**。

---

## 先に：画像生成では作らないでください

生成AIは日本語の細かい文字を正確に描けません。
**電話番号やメールが1文字化けた名刺を刷ると、全部刷り直しになります。**

分担はこうします。

| 担当 | やること |
|---|---|
| 文字・レイアウト | HTMLで版下 → 印刷用PDF。**文字は化けません** |
| ロゴ | 既存のものを配置 |
| Codex（画像生成） | 裏面の背景・図案だけ。**文字を含まない部分に限る** |

## 公式LINEは入れません

理由は3つです。

1. **初対面で渡すものです。**工務店・設計事務所の相手に、いきなり個人LINEの導線は距離が近すぎます
2. **QRが2つあると、どちらも読まれません。**名刺のQRは1つに絞るのが鉄則です
3. **HPにLINEへの導線があります。**HPのQRを1つ置けば、そこから辿れます

発信を見てほしい相手にはXがあり、依頼につなげたい相手にはHPがあります。
**LINEはHPの中に置いたままで足ります。**

## 面の構成

### 表（おもて）— 会社と名前だけ

初対面の3秒で「誰か」を覚えてもらう面です。**情報を詰めません。**

```
株式会社M&Go のロゴ

代表取締役
金子 麻里
Mari Kaneko

株式会社M&Go
〒151-0071 東京都渋谷区本町2-39-17
m-go.asia
```

- 余白を広く取る。**文字は氏名がいちばん大きい**（16〜18pt相当）
- ブランドカラー `#8BC5D1`（青緑）を細い線か小さな面で1か所だけ使う
- **肩書きの下に業務の説明を入れない。**そこは会話で埋める部分です

### 裏（うら）— 何をしている人かと、連絡先

渡したあと、机の上で見返される面です。

```
AI × 仕組み化

（ここに1行。下の候補から選ぶ）

────────────────

TEL   080-5432-9732
MAIL  m.kaneko@m-go.asia
WEB   m-go.asia
X     @mariSNSconsul

［QR：m-go.asia］
```

**1行の候補**（1つだけ選ぶ）

- 話すだけで、仕事が決まる仕組みをつくっています
- AIで、人がやらなくていい仕事を減らします
- SNS運用とAI導入の仕組み化を、実際に動くところまで

**QRは m-go.asia の1つだけ。** 複数置くと読まれません。

## KIMARIをどう扱うか

主体は会社なので、**KIMARIは名刺の主役にしません。**
ハッカソンのブースで渡すぶんだけ、裏の隅に小さく1行入れる案があります。

```
AI HACK 2026 出展　KIMARI（リノベAIエージェント）　kimari.vercel.app
```

これは**当日用の別バージョン**として刷るか、入れないかのどちらかです。
普段の仕事で配る名刺に、期間が終わったハッカソンの記載が残るのは避けたいところです。

**判断：まず通常版だけ作ります。**当日は配布資料（A4）にKIMARIの情報が全部入っているので、
名刺に入れなくても足ります。

## Codexへ頼む部分（画像生成）

**文字は一切入れないでください。** 生成するのは裏面の背景だけです。

```
名刺の裏面に敷く、抽象的な背景画像を作ってください。

・サイズ 97 × 61mm 相当（横長・解像度350dpi以上）
・色は #8BC5D1（青緑）と #FFC5D9（ピンク）を基調に、白の面を広く残す
・上に文字を載せるので、中央から右下は薄く、ほぼ白のままにする
・具体的なモチーフ（人・建物・パソコン）は描かない。線と面だけ
・グラデーションは弱く。印刷で濁るため、濃い色面を作らない
・文字・ロゴ・記号は一切入れない
```

生成したものは `docs/meishi/back.png` に置いてください。版下に読み込みます。

## 印刷所への入稿

- **サイズ**: 91 × 55mm（仕上がり）／ 97 × 61mm（塗り足し込み）
- **解像度**: 350dpi。PDFで入稿するのが確実
- **文字の余白**: 仕上がり線から3mm内側に文字を入れない（断裁でずれるため）
- **色**: CMYK指定を求められることがある。その場合は印刷所のテンプレートに合わせる

ネット印刷なら、テンプレート（Illustrator形式）を配っているところが多いので、
**先にテンプレートをダウンロードして、サイズだけ合わせる**のが安全です。
