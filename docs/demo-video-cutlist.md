## 画面収録の詳細（S04〜S08）

### 収録の共通設定

- 事前: mari@example.com でログイン → 田中様邸リノベーションを開いてトップ表示
- ビューポート 1920×1080、ブラウザUIなし（Playwrightのheadedウィンドウ）
- マウス移動はゆっくり・クリック前に一拍（slowMo設定）
- 各シーンは長回しで収録し、編集で倍速・カットする（収録尺は完成尺の2〜4倍でよい）

### S04 録音・文字起こし（完成21秒 / 収録60秒目安）

1. 現場ページ → 打ち合わせタブ
2. 「録音」押下 → 3秒待つ → 停止（波形が見える状態を2〜3秒）
3. 文字起こし欄へテキスト貼付（クリップボード注入で一括貼付）
4. 工事の段階「解体確認」を選択
5. PIIマスキング表示部へスクロール（氏名・住所の伏せ字を写す）★寄りで使う

### S05 仕分け（完成20秒 / 収録は実時間約80秒→編集で5〜8倍速）

1. 「仕分ける」押下
2. 処理中3段階の表示（個人情報を保護→最適なモデルを選択→会話を判断へ変換）を全部収録
3. 結果9件の一覧
4. 追加見積3件の位置へスクロール ★編集で発光演出
5. 黒い「認識のズレ」カードへ寄る（必須。他ツールにない差別化）

### S06 拾い出し（完成45秒・山場 / 収録は実時間約40秒待ち込みで長回し）

1. 「キッチン位置変更と給排水移設」カード → 「拾い出しを展開する」
2. 待ち時間も収録（編集で詰める）
3. 結果3項目（給水給湯管・排水管・継手・支持金物）を1つずつ写す
4. 「もともとの工事に含まれるので外したもの」を開いて一覧を写す
5. 資料・図面・写真タブ → 当初見積書の読み取り（64項目）へ
6. 拾い出しに戻り「現地で確認すること」を写す
※ 33→3の数字モーションはMGで別途作成し重ねる

### S07 追加見積書（完成25秒 / 収録60秒目安）

1. 「追加見積書をつくる」→ 見積書画面
2. 数量・単価を2〜3行入力（合計が変わる様子）
3. ひな型を「工事金額増減表」へ切り替え
4. 「印刷 / PDFで保存」→ プレビューを2〜3秒

### S08 施主ページ（完成19秒 / 収録45秒目安）

1. 施主ページ（/s/[token]）をヒーローから
2. 「プロジェクトの歩み」を横スクロール
3. 追加見積の理由の部分へ寄る
4. 質問ボタンの反応を1回
