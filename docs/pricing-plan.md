# 料金設計（たたき台）

採点項目②の評価軸は「誰が何にいくら払うか」。ここを曖昧にしない。

## 原則

**記録を「作る人」が払う。「読む人」は無料。**

打ち合わせの記録で困っているのは、あとで追加請求の説明をしなければならない側
（設計・工務店・現場監督）。職人と施主は困っている当事者ではなく、
受け取る側なので、課金対象にしない。

## 無料でできること

| 対象 | できること |
|---|---|
| **施主** | 共有リンクから確認書を読む。登録も不要 |
| **職人** | 共有された作業指示を読む（多言語含む）。無料アカウント登録可 |
| **職人** | **現場で録音して、依頼元へ送る** |

### 職人の録音を無料にする理由

現場で施主が職人へ直接「ここ、こうして」と言うのが、
最も揉める経路。設計は聞いておらず、記録も残らない。
**この経路を塞ぐことがサービスの価値の中心**なので、
職人に課金して使わなくなると、製品として意味がなくなる。

原価の負担は、送り先（依頼元の有料アカウント）が持つ。
録音は必ず案件に紐づくため、案件の持ち主が負担する形にする。

案件に紐づかない単独の録音は、悪用防止のため月3件までとする。

## 有料でできること（作る側）

| | 一人親方・個人設計 | 工務店 |
|---|---|---|
| 想定 | 1人 | 5人まで |
| 月額（たたき台） | **1,980円** | **9,800円** |
| 記録の件数 | 月30件 | 月150件 |
| 3文書の生成 | ○ | ○ |
| 多言語の作業指示 | ○ | ○ |
| 期限のリマインド | ○ | ○ |
| 案件ごとの保存・検索 | ○ | ○ |
| 共有リンクの発行 | 無制限 | 無制限 |

## 原価との関係

実測（`docs/benchmark.md`）では、打ち合わせ1件の処理が **0.42円**
（仕分け＋3文書＋多言語翻訳）。

月30件でも **12.6円**。サーバー費を含めても、月1,980円に対して原価は1%未満。

**価格は原価から決めていない。**
追加見積を1件取りこぼすと数万円の損失になるため、
その1件を防げれば月額の元が取れる、という基準で置いている。

## 競合との位置

| | 月額 | 性格 |
|---|---|---|
| KANNA | 0円〜 | 情報共有の箱。チャット・図面・工程 |
| 現場Plus | 60IDで10,000円 | 同上 |
| ANDPAD | 数万円〜 | 見積・原価まで一気通貫 |
| **KIMARI** | **1,980円〜** | **箱ではなく、箱に入れる中身を作る** |

既存の現場アプリを置き換えない。併用を前提にする。
生成した文書は、そのままKANNAや現場Plusのトークへ貼れる形で出す。

**乗り換えを求めないので、導入の障壁がほぼない。**

## 広がり方

職人が無料で使えることは、費用の話だけでなく流通の話でもある。

1. ある工務店がKIMARIを導入する
2. その現場の職人が、無料アカウントで指示を受け取る
3. 職人は別の工務店の現場にも入っている
4. そこで「うちの元請はこれ使ってる」と伝わる

職人は複数の元請を渡り歩くため、**職人を無料にすることが、
そのまま次の工務店への導線になる。**
