## 1. これは何か

建築・リノベーションの打ち合わせ音声から、**追加見積が必要な変更**と**期限**を見つけ、
施主・職人・社内それぞれ向けの文書に変えるプロダクト。

**議事録は作らない。** 議事録AIとの違いは「1つの会話から、宛先の違う3つの文書を作り分ける」点と、
「金額が動く変更かどうかを判定する」点。後者は建設業法上、変更時に書面での見積提示が
義務づけられていることに直結する。

タグライン: **話すだけで、現場が決まる。／ 会話を、次の仕事に変えるリノベAIエージェント。**

## 4. 処理の流れ

```
録音（MediaRecorder／全端末）
  ↓
文字起こし … faster-whisper（small）を自社サーバーで。/api/transcribe
  ↓
個人情報のマスク（lib/mask.ts）← ルーターへ出る手前で必ず通す
  ↓
仕分け（/api/analyze）… orcarouter/fusion-flash
  ↓ items[] （cost_impact / risk / decision_no_cost / pending）
  ↓
3文書＋翻訳（/api/documents）… 施主向け／職人向け／社内保存用
  ↓
現場に保存（data/projects/*.json）→ 施主ページへ自動反映
```

**音声そのものは外部サービスへ一切送らない。** 外へ出るのはマスク後のテキストだけ。

以前はブラウザ内蔵の音声認識（SpeechRecognition）も併用していたが、外した。
Chromeの実装は音声をGoogleのサーバーへ送るため、上の一文と両立しない。
**同じ理由で、その場で文字になる系の機能を足すときは必ず送信先を確認すること。**

| `lib/files.ts` | ファイル保存 | Node専用 |
| `lib/file-kinds.ts` | 種別の定数・型 | **クライアントはこちらを読む** |
| `lib/auth.ts` | 認証（scrypt） | Node専用 |
| `lib/roles.ts` | 役割の定数・型 | **クライアントはこちらを読む** |

### 落とし穴（2回踏んだ）

**クライアント側のコンポーネントから `lib/files.ts` や `lib/auth.ts` を読んではいけない。**
`node:fs` がブラウザ用のバンドルに混ざり、Turbopackがビルドに失敗する。
定数と型は `file-kinds.ts` / `roles.ts` に分けてあるので、クライアントはそちらを読む。

## 6. 実測値（発表で使う）

### コスト（`docs/benchmark.md` に詳細）

| 指定 | 実モデル | 所要 | 概算原価 |
|---|---|---|---|
| `anthropic/claude-opus-5`（直指定） | claude-opus-5 | 99秒 | **約35.2円** |
| `orcarouter/fusion-flash` | qwen3.7-flash | 47秒 | **約0.13円** |

**約270分の1。** しかも追加見積3件の判定は全モードで一致した。
ただし「認識のズレ」の検出は opus が3件、安いモデルは1件。
→ **仕分けは安いモデル、含みのある会話の精査だけ高いモデル**という構成にした理由。

### 実際の打ち合わせ（8分16秒・2,532文字）

- 仕分け → **0.18円 / 82秒**
- 仕分け＋3文書＋ベトナム語訳 → **0.42〜0.51円 / 5回の呼び出し**
- 文字起こし → **0円**（ローカル）

### 精度

- 抽出9件。仕込んだ判定（追加見積3件・認識のズレ・保留・期限）をすべて捕捉
- **文字起こしの誤認識を文脈から復元した**
  「縦側」→建具、「特選期」→食洗機、「多く」→オーク
- 期限の換算: 「今週中」→2026-08-14、「来週」→2026-08-16

## 7. 実機検証で潰した不具合（記事に書ける）

| 症状 | 原因 | 対処 |
|---|---|---|
| ログインボタンが押せない | iOSの自動入力が変更イベントを出さない | 入力状態での無効化をやめ、送信時にフォームから読む |
| 押すと素の再読み込み | 開発モードのJSがその環境で動かず | 本番ビルドで解消。フォーム送信経路も追加 |
| ログインしても弾かれる | **本番ビルドのSecureクッキーをhttpのiPhoneが拒否** | `secure: false`（公開時はtrueへ戻す） |
| リダイレクト先が 0.0.0.0 | 開発サーバーが `req.url` のホストを書き換える | 相対Locationで返す |
| 押せる要素が矢印カーソル | Tailwind v4で既定が変わった | globals.cssで一括指定 |
| ビルドが壊れる | クライアントがNode専用モジュールを読んでいた | 定数・型を別ファイルへ分離 |
